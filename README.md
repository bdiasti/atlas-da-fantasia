# Atlas da Fantasia

Árvore interativa de influências da fantasia, com livros, filmes, séries e jogos.

## Código-fonte

- `index.html`: estrutura e navegação.
- `styles.css`: layout responsivo.
- `app.js`: árvore de influências e fichas.
- `materials.js`: catálogo e links de consumo.

O site usa HTML, CSS e JavaScript diretamente, sem compilação e sem dependências.

## GitHub Pages

Em Settings → Pages, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**. Os caminhos dos arquivos são relativos e funcionam no endereço do projeto.

As fichas incluem referências. Os links de onde assistir consultam a disponibilidade no Brasil; preços e catálogos podem mudar.
